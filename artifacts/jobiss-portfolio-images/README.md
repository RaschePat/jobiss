## 상태와 제작 방식

- actual: 현재 로컬 서비스의 실제 브라우저 캡처. 입력 기반 체험 모드이며 실제 채용 데이터가 아닙니다.
- design: 현재 서비스의 색상·타이포그래피를 참고해 작성한 HTML 설계 화면을 브라우저에서 캡처했습니다. 버튼은 정적인 시각 표현이며 기능 구현을 의미하지 않습니다.
- 00-representative: 실제 캡처 2장을 HTML에 배치한 소개용 구성입니다.
- 11-data-flow: 실제 연동 응답이 아닌 현재 상태와 후속 연동 설계를 구분한 설명 자료입니다.
- 12-validation-plan: 검증 예정 기록 양식입니다. 테스트 성과나 사용자 수를 주장하지 않습니다.
- 이미지 생성 AI를 사용하지 않았습니다. 한국어 문구를 정확히 유지하기 위해 실제 화면과 HTML 목업을 캡처했습니다.

예시 입력: “인터뷰 내용을 정리하고 회의에서 서비스 개선안을 제안했다.”
이름은 화면 연결을 위한 예시입니다. 입력은 사용자의 실제 경력 사실로 취급하지 않았습니다.
촬영에는 127.0.0.1의 별도 브라우저 저장 공간을 사용해 기존 localhost 입력을 보존했습니다.
