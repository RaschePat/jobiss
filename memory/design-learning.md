# Design Learning Memory v0.2

## Purpose
Store observed user judgments from prior Jobiss design evaluations. Treat them as evidence about priorities and decision criteria, not as a style recipe. Apply only when relevant.

## Visual Quality
- The user currently ranks prior visual results: `Y1 > X2 > Y2`.
- Y1 was preferred because its bespoke generated visual, editorial/document system, typography, composition, and color placement formed the strongest coherent visual world.
- X2 was preferred over Y2 because each section had a stronger, more immediate composition and content presence, although X2's typography felt too dense.
- The target is not merely a polished SaaS landing page. Preserve room for authored art direction, bespoke visual material, controlled scale contrast, and section-specific visual impact without losing coherence.

## User Entry Point & Storytelling
- Both X2 and Y2 were judged stronger than Y1 in content flow and storytelling.
- The user especially liked Y2's hero line: `무슨 일을 잘할지, 아직 몰라도 괜찮아요.` because it begins from the job seeker's uncertainty rather than from a service explanation.
- Prefer a narrative that begins with the user's lived problem and makes the transformation through Jobiss understandable, rather than merely listing feature order.

## Product Storytelling
- Preserve the progression: discover possibilities → understand why they fit → see gaps → know what to prepare or do next.
- The line `합격 가능성보다 준비할 방법을 알려줘요.` was specifically valued because it expresses this principle clearly.
- Visual sophistication must not weaken this value progression.

## Mailbox / Arrival Metaphor
- The mailbox/arrival idea remains a strong Jobiss metaphor.
- Re-express arrival within the chosen visual world rather than mechanically reusing a cartoon mailbox or previous composition.
- The arrival moment should help users feel that a possibility or posting has reached them, not merely decorate the page.

## Product UI / Mockups
- Product UI is evidence that Jobiss actually works; it does not automatically need to dominate a section.
- Reposition, crop, or reframe mockups when the product metaphor or art direction should lead the composition.

## Ending
- Treat the ending as a deliberate final composition with brand impact, not a generic centered CTA afterthought.

## Generalized Decision Principles
1. Seek Y1-level visual sophistication and X2/Y2-level storytelling rather than trading one for the other.
2. Start from a recognizable user tension when that creates stronger empathy.
3. Prefer authored visual systems over familiar AI/SaaS assembly when product clarity remains viable.
4. Art direction should amplify product meaning, not replace it.
5. Communicate `what fits me?`, `why?`, `what is missing?`, and `what should I do next?`.
6. Reuse product metaphors conceptually, not by copying prior visual objects.
7. Avoid excessive typographic density even when using bold editorial scale.
8. Use remembered judgments as priorities and constraints, not instructions to recreate a previous page.

## Guardrails
- Do not mention this memory file unless asked.
- Do not copy prior layouts, assets, or exact compositions merely because they were preferred.
- These observations are strongest for Jobiss and adjacent design tasks.
- Current explicit user instructions and product context override memory.
