# 잡이쓰 · 첫 사용자 온보딩

관심 선택 → 경험 한 줄 → 직무 가능성 → 첫 커리어 편지로 이어지는 한국어 온보딩입니다.

## 실행

```sh
npm install
npm run dev
```

기본 주소는 `http://localhost:3000`입니다. 다른 서버가 사용 중이면 `PORT=3008 npm run dev`처럼 포트를 지정하세요.

```sh
npm test
npm run lint
npm run build
PORT=3009 npm start
```

## 구현 범위

- 8가지 관심 복수 선택, 선택에 반응하는 편지 미리보기
- 관심만 또는 경험만으로 분석 시작, 이름 선택 입력
- 직무 가능성과 연결 근거 확인, 탐색 방향 선택
- 체험 우편함, 개인화 연결 설명, 확인할 점, 다음 행동과 완료 표시
- 공고 저장·넘김·복원, 경험 추가와 재분석
- 버전이 있는 브라우저 임시 저장과 새로고침 복원
- 빈 입력 차단, 분석 중 중복 요청 방지, 45초 타임아웃, 실패 시 입력 유지와 재시도
- 반응형 화면, 키보드 포커스, 네이티브 모달, 모션 줄이기 대응

## 데이터 및 연결

실제 계정과 채용 데이터베이스는 연결되어 있지 않습니다. 첫 우편함은 기존 예시 기업과 직무 데이터를 활용한 **체험 공고**이며, 화면에서도 명시합니다. 실제 채용 지원·이메일 발송은 수행하지 않습니다.

`GEMINI_API_KEY`가 없으면 입력된 관심과 키워드에서만 잠정 방향을 만드는 체험 분석을 제공합니다. 키가 있으면 기존 Gemini 분석 경로를 사용합니다. 실제 Gemini 호출은 키가 없는 이 환경에서 검증하지 않았습니다.

이름, 경험, 결과, 선택은 브라우저의 `jobiss.onboarding.v1` 키에 저장합니다. 분석 요청에는 경험과 관심만 보냅니다. 포트폴리오·GitHub 링크를 적을 수 있지만 링크 내용을 자동 수집하지는 않습니다. 도움말에서 이 브라우저의 입력을 초기화할 수 있습니다.

설계 의도는 [온보딩 설계 문서](experiment-context/onboarding-design.md)를 참고하세요.
