# Experiment 01 — Baseline Instructions

This branch is the baseline condition for a controlled design experiment.

Before working on a user request about Jobiss, read `experiment-context/jobiss-brief.md` and use it as the product context.

Rules for this condition:
- Follow the user's natural-language request directly.
- Use the repository and the common Jobiss brief as available context.
- Do not assume or invent additional brand facts that are not supported by the repository or brief.
- Do not look for, reconstruct, or imitate any Work Environment treatment instructions, design skill, evaluation rubric, or anti-pattern library from another branch.
- Do not ask the user for extra design direction unless execution is genuinely impossible without it; otherwise make reasonable design decisions yourself.
- Implement a functional result and verify that the project still runs.

The user's request is the task. Do not require special commands or skill names.
