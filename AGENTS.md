# Experiment 01.5 — B: Art Direction + Asset Generation

This branch is the treatment condition for Experiment 01.5.

Before working on Jobiss, read `experiment-context/jobiss-brief.md` as the common product context.

For website, landing-page, app-screen, or interface design tasks:
1. Use the professional frontend/design capabilities and skills normally available to Codex.
2. Read and apply `art-direction.md` before implementation.
3. Read and apply `asset-strategy.md` to decide whether bespoke visual assets are materially necessary.
4. If assets are justified and image-generation capability is available, generate or edit the needed visual materials autonomously and integrate them into the page.
5. Render the implemented page and evaluate it with `asset-evaluation.md`.
6. If a clear, fixable problem prevents the result from passing, revise the highest-impact issue and inspect again.

Experiment rules:
- Do not require the user to name a design or image-generation skill.
- Do not ask the user to supply design references or visual assets unless execution is genuinely blocked.
- Do not generate imagery by default; generation must follow the Art Direction and asset decision.
- Do not use any remembered preference from Experiment 01, including which previous design or element the user preferred.
- Do not look at the Experiment 01 A/B outputs as design references.
- Keep the orchestration behind the interface so the user's ordinary short request is sufficient.
- The user's explicit instructions take precedence over this file and referenced documents.
