# 1층 도착 이유 문구 · 2026-09-11

매일 도착하는 공고 카드에 "왜 이게 왔는지"를 쓰는 규칙이다. [`product-plan.md`](product-plan.md) 6·8절을 따른다.

---

## 1. 이 문구가 해야 하는 일

본문이 없으므로 깊은 분석은 못 한다. 그런데 얕아도 **정확히 겨냥하면 문제 3번과 4번에 직접 닿는다.**

- 문제 3 — 공고를 일일이 뜯어볼수록 "나는 다 안 맞는다"는 신호가 돌아와 지친다
- 문제 4 — 요건을 다 채워야 지원할 수 있다고 믿어 출발이 늦어진다

그래서 1층 문구의 목표는 적합도를 설명하는 게 아니라 **"이건 네가 지금 지원할 수 있는 자리다"를 확정적으로 말해주는 것**이다. 사용자가 자격을 스스로 검열하지 않아도 되게 만든다.

핵심 문장은 하나다.

> **지원 자격은 확인했어요.**

경력과 학력은 API가 코드로 주므로 이건 추측이 아니라 사실이다. 이 한 줄이 1층의 존재 이유다.

---

## 2. 말할 수 있는 것 / 없는 것

카드에서 **확정과 정황을 반드시 시각적으로 구분**한다. 섞어 쓰면 그게 환각이다.

### A. 확정 — 단정해도 되는 것
API 코드와 프로필을 대조해 참·거짓이 정해지는 것만.

| 근거 | 출처 |
|---|---|
| 신입 지원 가능 / 경력 무관 | `experience-level@code` (1·0·3) |
| 요구 경력 연차 | `experience-level@min`, `@max` |
| 학력 조건 충족 | `required-education-level` × 프로필 학력 |
| 근무지 | `location` |
| 고용형태 | `job-type` |
| 마감 | `expiration-timestamp`, `close-type` |

### B. 정황 — 사실이되 의미는 단정하지 않는 것
겹친다는 것까지만 말하고, 그래서 적합하다고는 말하지 않는다.

| 근거 | 출처 |
|---|---|
| 공고 키워드 ∩ 프로필 키워드 | `keyword` 배열 |
| 탐색 방향과 같은 직무 | `job-code`, `job-mid-code` |
| 본문에 내 키워드가 언급됨 | `keywords` 파라미터 탐침 결과 |

### C. 말하지 않는 것
- 적합도 점수·퍼센트·별점
- "잘 맞아요", "딱 맞는 자리예요", "당신을 위한 공고"
- 자격요건을 **충족한다/부족하다** — 본문이 없으므로 알 수 없다
- 사용자가 제공하지 않은 경력·역량
- 실제 채용 가능성, 합격 가능성

> **근거는 사용자가 실제로 적은 것에서만 나온다.** 프로필에 학력이 없으면 학력 줄을 쓰지 않는다. 대조하지 않은 것은 적지 않는다.

## 3. 카드 구조

순서가 중요하다. **허락이 먼저, 연결이 나중이다.**

```
회사명
공고 제목

✓ 지원 자격 확인   신입 지원 가능 · 학력 조건 충족      ← 확정
  서울 중구 · 정규직 · D-23

· 겹치는 키워드   서비스기획, 콘텐츠                    ← 정황

  주요업무와 자격요건 전문은 사람인에서 →               ← 정직한 경계
```

- **✓ (확정)과 · (정황)은 다른 기호·다른 색으로** 둔다. 정황을 확정처럼 보이게 하지 않는다
- 마지막 줄은 빼지 않는다. 우리가 본문을 모른다는 사실을 숨기면 신뢰가 깨진다. 사람인으로 연동하는 정상 경로이기도 하다
- 출처가 사람인임을 표시한다 (약관 요구사항)

## 4. 케이스별 문구

### 경력 조건 (항상 첫 줄)

| `experience-level@code` | 문구 |
|---|---|
| 1 (신입) | **신입 지원 가능** |
| 0 (경력무관) | **경력을 보지 않는 자리** |
| 3 (신입/경력) | **신입도 지원 가능** |
| 2 (경력) | 1층에서 보내지 않는다 (7절) |

### 연결 이유 (둘째 줄) — 위에서부터 먼저 해당하는 하나만

1. **키워드가 겹칠 때**
   > 겹치는 키워드 · 서비스기획, 콘텐츠

2. **본문 탐침이 히트했을 때**
   > 공고 본문에 '공간기획'이 언급돼요

3. **겹침은 없지만 고른 방향과 같은 직무일 때**
   > 탐색 방향으로 고른 서비스 기획 직무예요

4. **셋 다 없을 때** → 보내지 않는다

### 전체 예시

실제 공고(참좋은여행, IT 서비스 기획자, 신입, 서울 중구, D-23) 기준.

```
참좋은여행(주)
IT 서비스 기획자 채용 (신입)

✓ 지원 자격 확인   신입 지원 가능
  서울 중구 · D-23

· 겹치는 키워드   서비스기획

  주요업무와 자격요건 전문은 사람인에서 →
```

프로필에 학력이 있고 키워드가 여럿 겹치는 경우.

```
(주)아티언스
[AX/신입] AI서비스 기획자(PM/PO)

✓ 지원 자격 확인   신입 지원 가능 · 학력 조건 충족
  서울 마포구 · D-4

· 겹치는 키워드   서비스기획, PM, 데이터

  주요업무와 자격요건 전문은 사람인에서 →
```

## 5. 금지 표현 대조

| 쓰지 않는다 | 대신 |
|---|---|
| 당신에게 딱 맞는 공고예요 | 신입 지원 가능한 자리예요 |
| 적합도 82% | (쓰지 않음) |
| 자격요건을 충족합니다 | 지원 자격은 확인했어요 (경력·학력만) |
| AI가 분석한 결과 추천합니다 | 이래서 왔어요 |
| 이 직무가 당신의 천직입니다 | 탐색 방향으로 고른 직무예요 |
| 지금 지원하면 합격 가능성이 높아요 | (쓰지 않음) |

## 6. 하루치 묶음 문구

카드 위에 붙는 한 줄. 개수를 부풀리지 않는다.

```
오늘 3건이 도착했어요. 모두 신입이 지원할 수 있는 자리예요.
```

0건일 때 채우지 않는다.

```
오늘은 조건에 맞는 공고가 없었어요.
관심사를 넓히거나 지역을 늘리면 더 찾을 수 있어요.
```

## 7. 배송 필터 규칙

문구가 아니라 무엇을 보낼지의 규칙이지만, 문구의 정직성이 여기 달려 있다.

- **지원할 수 없는 공고는 보내지 않는다.** 경력을 요구하는 자리(`code=2`)는 제외한다. "조금만 더 준비하면 닿는다"는 말은 본문이 없어 무엇을 더 준비할지 말할 수 없으므로 하지 않는다
- 학력 조건이 프로필보다 높으면 제외한다
- 마감된 공고(`active=0`)는 제외한다
- **도착 이유를 한 줄로 쓸 수 없으면 보내지 않는다.** 채우기용 공고를 넣지 않는다
- 호출 500회/일 제한이 있으므로 사용자당 배송 건수와 본문 탐침 횟수에 예산을 둔다

## 8. 남은 것

- `keyword` 배열의 실제 밀도는 access-key 발급 후 확인한다. 겹침이 거의 안 생기면 2번 연결 이유 규칙을 다시 짠다
- 본문 탐침의 정확도도 실측이 필요하다. 오탐이 잦으면 3번 규칙에서 내린다
- 편지 톤을 어디까지 입힐지는 실제 카드를 만들어보고 정한다. 지금 문구는 정직성 기준이고 최종 카피가 아니다
