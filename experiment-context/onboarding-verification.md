# 온보딩 검증 결과 · 2026-09-08

사용자 관심/경험 입력 → 분석 API → 잠정 직무 선택 → 첫 우편함 → 공고 저장과 준비 행동까지 검증했다.

- `npm test`: 6개 통과. 모든 관심 경로, 경험만 입력, 정보 부족, 예시 경력 혼입 방지, 재분석 시 피드백 유지, 분석 실행과 무관한 공고 ID를 검사.
- `npm run lint`: TypeScript 검사 통과.
- `npm run build`: 클라이언트와 서버 빌드 통과. 기존 CJS 서버의 `import.meta.url` 문제를 제거하고 `npm start`가 production 모드로 실행되도록 수정.
- 프로덕션 서버(`PORT=3009 npm start`): 정적 HTML/자산 및 API 정상 제공.
- API: 빈 입력, 태그 타입 오류, null 본문, 2,000자 초과 입력에 400 응답. SQL 경험만 입력하면 데이터 분석가 체험 결과 반환.
- 브라우저: 관심 복수 선택 시 미리보기 반영, 이름·경험 입력, 저장하고 나가기, 새로고침 후 단계와 입력 복원 확인.
- 브라우저: 관심을 건너뛰고 경험만 입력하는 경로, 빈 입력 시 분석 버튼 비활성 확인.
- 브라우저: 디자인·콘텐츠 방향 선택, 첫 우편함, 개인화 설명과 다음 준비 행동, 완료 체크, 저장·넘김·되돌리기 및 새로고침 후 저장 상태 유지 확인.
- 실패 복구: 개발 서버를 정지하고 분석을 요청해 오류와 입력 보존 확인. 영어 네트워크 오류를 한국어 안내로 수정한 뒤 재검증. 서버 복구 후 동일 입력으로 분석 재시도 성공.
- 390×844 모바일: 첫 선택 화면 및 결과 화면 확인. 결과 화면 viewport/page width 모두 390px로 가로 넘침 없음.
- 최종 프로덕션 첫 화면: 브라우저 오류·경고 로그 없음.

## 검증하지 않은 외부 연결

환경에 `GEMINI_API_KEY`가 없어 실제 Gemini 분석은 검증하지 않았다. 입력 기반 체험 분석과 예시 공고를 사용한다. 실채용 데이터 수집, 계정 동기화, 채용 지원, 알림 발송은 이 온보딩 구현에 연결되어 있지 않다.
