# 첫 사용자 온보딩

## 목적과 흐름
직무를 정하지 못한 사람도 관심 한 가지로 시작하고, 자신의 입력이 직무 가능성과 공고의 도착 이유로 연결되는 것을 경험한다.

1. 관심: 8개 관심 분야 중 복수 선택. 모르면 경험 입력으로 이동.
2. 경험: 짧은 설명과 선택적 이름. 관심만으로도 분석 가능. 학력·교육·자격증·프로젝트·포트폴리오·GitHub 등 자유롭게 추가.
3. 발견: 근거가 있는 잠정 직무를 보여주고 사용자가 탐색 방향을 선택.
4. 우편함: 선택 방향의 체험 공고, 연결 이유, 확인할 역량, 다음 준비. 저장·넘김·되돌리기와 경험 보충 및 재분석.

## 시각 방향
- 색: 종이 #FFFFFF, 바탕 #F7F9FB, 잉크 #182B3E, 보조 #647487, 브랜드 #ADD6FF, 선택 #EAF4FF.
- 글꼴: 한국어 Pretendard, 워드마크 Arial. 제목 40px, 본문 16px, 안내 13px.
- 구성: 상단 워드마크와 임시 저장, 왼쪽 입력·단계·다음 행동, 오른쪽 푸른 편지 미리보기. 입력과 동시에 편지의 내용이 달라진다. 모바일에서는 입력을 먼저, 미리보기는 아래로 배치.
- 기억할 한 가지: 입력한 관심이 편지의 수신 맥락으로 바뀌는 장면. 장식용 이미지 대신 실제 상태에 반응하는 HTML/CSS 편지.

```
jobiss.                                      저장하고 나가기
───────────────────────────────────────────────────────────
관심 ───── 경험 ───── 발견       │  당신에게 도착할 첫 가능성
아직 직무를 몰라도,             │
좋아하는 것부터.               │       관심에 반응하는
                               │        첫 번째 편지
관심 선택 2열                  │
                               │
다음                           │  관심 → 연결 → 기회
```

일반 가입 양식이나 기능 소개 캐러셀 대신 핵심 가치와 직접 연결되는 관심 수집으로 시작한다. 편지는 별도 홍보 화면이 아니라 현재 입력의 즉각적 피드백이다. 숫자 적합도·가짜 공고 수·사용자가 제공하지 않은 경력은 표시하지 않는다.

## 상태와 정직성
- 버전이 있는 브라우저 저장: 중간 입력, 단계, 분석 결과, 선택 방향, 공고 피드백, 준비 완료 상태를 복원.
- 초기 사용자에게 기존 민석 프로필을 주입하지 않는다.
- API 키가 없으면 입력 기반 규칙 분석으로 동작하며 체험 결과임을 표시한다.
- 기존 예시 채용 데이터는 항상 체험 공고로 표시. 실제 채용 여부나 발송 알림을 약속하지 않는다.
- 분석 중 중복 전송 방지, 실패 시 입력 유지 및 재시도, 빈 입력 차단, 관심만/경험만 경로 제공.
- AI 결과는 확정 진단이 아니라 탐색 가능성. 사용자가 방향을 선택한다.
