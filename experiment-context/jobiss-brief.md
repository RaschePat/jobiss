# Jobiss Brief v0.2 — Common Input

## Product
Jobiss(잡이쓰)는 취업 준비 사용자가 자신의 학력, 교육, 자격증, 프로젝트, 포트폴리오, GitHub, 관심사를 등록하면 AI가 이를 분석해 직무와 채용공고 탐색을 돕는 커리어 서비스다.

## Problem
사용자는 자신이 어떤 직무와 맞는지, 지금까지의 경험을 어떻게 연결해야 하는지, 무엇이 부족하고 다음에 무엇을 준비해야 하는지 판단하기 어렵다.

## Core Flow
1. 사용자 정보 등록
2. AI 분석
3. 적합한 채용공고 도착
4. 관심 공고 선택
5. AI가 사용자 정보와 공고를 비교
6. 적합 근거, 부족 역량, 다음 행동 제안

## Main Features
- Profile
- AI Analysis
- Job Mailbox
- Job Fit Report
- Next Action

## Target User
- 취업 방향을 탐색 중인 구직자
- 자신의 경험을 직무/공고와 연결하기 어려운 사용자

## Repository Status — Important Context
현재 `src/`의 구현은 Jobiss의 기능과 흐름을 검증하기 위해 만든 **이전 모바일 앱 프로토타입**이다.

이 프로토타입에는 다음과 같은 과거 표현이 남아 있다:
- 390×844 모바일 디바이스 프레임
- 8개 모바일 화면 갤러리
- `#4A6CF7` 중심의 과거 블루 스타일
- 아이콘 + 한글 `잡있으` 로고 표현

이 요소들은 현재 랜딩페이지의 디자인 방향이나 브랜드 기준이 아니다.

기존 코드는 아래 용도로만 해석한다:
- 실제 제품 기능 파악
- 사용자 흐름 파악
- 인터랙션과 데이터 구조 파악
- 랜딩에서 보여줄 수 있는 실제 제품 순간의 원천

랜딩페이지를 디자인할 때 기존 모바일 프레임, 8-screen gallery, 과거 색상/로고를 단순 재사용할 필요가 없다.

**"기존 기능 유지"는 제품 기능과 핵심 흐름을 보존하라는 의미이며, 기존 모바일 프레젠테이션이나 화면 목업 형식을 그대로 유지하라는 의미가 아니다.**
