# Jobiss Brief v0.3 — Common Input

## Product
Jobiss(잡이쓰)는 취업 준비 사용자가 자신의 학력, 교육, 자격증, 프로젝트, 포트폴리오, GitHub, 관심사를 등록하면 AI가 이를 분석해 직무와 채용공고 탐색을 돕는 커리어 서비스다.

## Problem
사용자는 자신이 어떤 직무와 맞는지, 지금까지의 경험을 어떻게 연결해야 하는지, 무엇이 부족하고 다음에 무엇을 준비해야 하는지 판단하기 어렵다.

## Core Flow
1. 사용자 정보 등록
2. AI 분석
3. 적합한 채용공고 도착
4. 관심 공고 선택
5. AI가 사용자 정보와 공고를 비교
6. 적합 근거, 부족 역량, 다음 행동 제안

## Main Features
- Profile
- AI Analysis
- Job Mailbox
- Job Fit Report
- Next Action

## Target User
- 취업 방향을 탐색 중인 구직자
- 자신의 경험을 직무/공고와 연결하기 어려운 사용자

## Repository Status — Important Context
이 실험 브랜치에서는 과거 모바일 프로토타입의 **시각 UI 구현을 의도적으로 제거했다.**

제거된 과거 표현에는 다음이 포함됐다:
- 390×844 모바일 디바이스 프레임
- 8개 모바일 화면 갤러리
- `#4A6CF7` 중심의 과거 블루 스타일
- 아이콘 + 한글 `잡있으` 로고 표현
- 기존 모바일 화면 컴포넌트와 프레젠테이션용 UI

따라서 이 브랜치에는 랜딩 디자인이 따라야 할 기존 화면이 없다.

남아 있는 `src/data`, `src/types.ts`, 서버 로직과 `experiment-context/functional-map.md`는 **제품 기능과 데이터/행동 구조를 이해하기 위한 근거**다.

과거 모바일 UI를 Git history에서 복구하거나 재구성할 필요가 없다.

**"기존 기능 유지"는 제품의 핵심 capability와 사용자 흐름을 보존하라는 의미이며, 과거 UI 형식이나 화면 목업을 복원하라는 의미가 아니다.**
